        -: SOC Analyst Lab – Security Monitoring and Incident Investigation using Splunk Enterprise :-

* This project was developed as part of my Cybersecurity learning journey to gain hands-on experience with Splunk Cloud SIEM
  and understand practical Security Operations Center (SOC) activities.
* In this project, I built a small SOC lab environment using Splunk Cloud, Windows VM, Kali Linux VM, VMware Workstation, and Splunk Universal Forwarder.
* The Windows VM was configured as the monitored endpoint and Kali Linux was used for security testing and attack simulation.
* The main objective of this project was to understand how Windows security events are generated, collected through the Splunk Universal Forwarder,
  sent to Splunk Cloud, searched using SPL queries, and investigated from a SOC analyst perspective.
* I performed different security activities on the Windows endpoint and analysed the generated events in Splunk Cloud.
* The project helped me understand the complete workflow of
Log generation → log collection → SIEM search → alert investigation → incident classification.
